# Problem Statement
As college students, we spend too much time on laptops and phones without realising how much time is wasted on Instagram or YouTube versus actual studying. It is hard to keep track of this balance.

# Scope of the Project
This Python project lets a user log what apps they use and calculates a productivity score for them. It helps show if they have a healthy digital routine. Data is saved locally in a simple CSV file.

# Target Users
College students who want to track their study-to-entertainment screen time balance to improve their focus.

# High-Level Features
1. Save screen time data locally using CSV.
2. Calculate total minutes and productivity percentage across all apps.
3. Draw a text-based bar chart graph using asterisks (*).
4. Provide a basic health status report based on daily screen time.
